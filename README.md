# Handwritten Character Recognition

## Overview
This project recognizes handwritten characters using Machine Learning and Deep Learning techniques.

## Features
- Recognizes handwritten alphabets and digits
- Image preprocessing
- Character prediction
- User-friendly interface

## Technologies Used
- Python
- TensorFlow/Keras
- OpenCV
- NumPy
- Matplotlib

## Installation
```bash
git clone https://github.com/Arundhathi-27/CodeAlpha_HandwrittenCharacterRecognition.git
cd CodeAlpha_HandwrittenCharacterRecognition
pip install -r requirements.txt
```

## Run
```bash
python app.py
```
